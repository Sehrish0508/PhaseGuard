PhaseGuard

Electrical fault classifier dashboard


A machine learning powered web app that detects and classifies electrical faults on a 3-phase power line in real time.

Project Description

PhaseGuard classifies electrical faults on a 3-phase power line using a randomforest model trained on current and voltage readings.


Move the sliders to simulate live readings and see the model's live prediction.


Predictions update instantly as you move any slider, so no prediction button needed.


Note: current values reflect real sensor readings; voltage values are normalized (per-model convention), so they appear as small decimals rather than real volts.

Note: confidence may look moderate (30-50%) with slider inputs, since sliders can only approximate exact values. On the original test dataset, the model achieved 98-100% accuracy and confidence — this reflects input precision, not model quality.
